# Vietnamese and English lettering

Pixel letters and recipes: docs/all-7-fonts-json.zip, composed according to docs/quy-tac-ghep.md. These are the authoritative letter shapes.

SIL Open Font License; each supporting font license is included beside its font.

- dancing: https://github.com/google/fonts/tree/main/ofl/dancingscript (DancingScript[wght].ttf)
- allura: https://github.com/google/fonts/tree/main/ofl/allura (Allura-Regular.ttf)
- vibes: https://github.com/google/fonts/tree/main/ofl/greatvibes (GreatVibes-Regular.ttf)
- lobster: https://github.com/google/fonts/tree/main/ofl/lobster (Lobster-Regular.ttf)
- playfair: https://github.com/google/fonts/tree/main/ofl/playfairdisplay (PlayfairDisplay[wght].ttf)
- coiny: https://github.com/google/fonts/tree/main/ofl/coiny (Coiny-Regular.ttf)
- caveat: https://github.com/google/fonts/tree/main/ofl/caveat (Caveat[wght].ttf)

Supporting outlines provide numbers and punctuation; font advances and kerning place the pixel letters on their shared baseline. Variable fonts use the weights specified in the supplied library. Rebuild from the ZIP: npm run fonts:prepare. No font download is needed at runtime.
